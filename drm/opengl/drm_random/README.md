# Minimal DRM for OPENGLES - Random colors

Improvement of the code located upon `./opengl/drm` this tiome I change color every 5 seconds. This demo is used to illustrate the pageflips.

## Build steps

### Setup Dependencies:

```
sudo apt install build-essential pkg-config libdrm-dev libgbm-dev libegl-dev libgles-dev mesa-utils libgl1-mesa-dri libdrm-dev
```

### Build

```
make clean
make
```

## Run:

```
./main
```
